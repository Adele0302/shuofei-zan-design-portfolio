# Pixel Cat — a tiny interactive webpage

The old guestbook has been intentionally replaced with one thing: a full-screen, pettable pixel cat.

**Live paths after GitHub Pages publishes:**

- Home: https://adele0302.github.io/shuofei-zan-design-portfolio/
- Previous guestbook URL: https://adele0302.github.io/shuofei-zan-design-portfolio/guestbook/

Both URLs display the same self-contained cat; neither displays a guestbook, input form, feed, navigation, counters, or other visible text.

## Interaction

- Click or tap the cat to make it hop, close its eyes, wag its tail and show small hearts.
- Holding and moving a pointer over the cat produces more petting reactions.
- Keyboard users can Tab to the cat and press Space or Enter.
- Reduced-motion preferences disable movement effects. The cat remains accessible.

The illustration is original inline SVG pixel art; no JavaScript framework, network request, external image, API token, database, user account or analytics service is required.

The older guestbook's existing GitHub Issues, if any, are **not deleted**. Their display and submission interface have simply been removed.

To deploy, use the repository's **main** branch and **/docs** directory under Settings → Pages.
